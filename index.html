🔎 거리점검 방법

  1. 파일 가져오기에듀파인에서 내려받은 관내여비 엑셀을 선택합니다.
  2. 근무지 설정실제 출장 출발 위치에 가까운 학교 정문 또는 주 출입구를 지정합니다.
  3. 거리점검출장지 위치를 확인한 뒤 근무지 ↔ 출장지 보행 왕복거리를 계산합니다.
  4. 결과 확인출장별 왕복거리와 2km 여부, 추가 확인사항을 확인합니다.

⚠️ 결과는 이렇게 봐주세요

콕검의 거리 결과는 출장여비 검토를 돕기 위한 확인자료입니다. 지도에서 계산한 보행거리는 실제 출장 경로와 차이가 있을 수 있습니다.

  • 장소명이 불분명하거나 같은 이름의 장소가 여러 곳인 경우
  • 학교 또는 출장지의 실제 출입구가 지도 위치와 다른 경우
  • 왕복 2km 기준과 가까운 경우
  • 실제 이동수단이나 교통비 발생 여부 확인이 필요한 경우

최종 여비 지급 여부는 관련 여비 지침과 소속 기관의 적용 기준을 확인해 판단해 주세요.

📊 TMAP 사용량 보호

보행 왕복거리 1곳을 계산할 때 TMAP 경로조회 2회를 사용합니다. 오늘 사용량은 모든 사용자 기준으로 함께 집계합니다.

  • 공식 무료 제공량: 하루 1,000회
  • 콕검 경고 시작: 800회
  • 콕검 자체 안전한도: 900회

이번 점검으로 안전한도를 넘을 것으로 예상되거나 사용량 저장소를 확인할 수 없으면 신규 거리계산을 시작하지 않습니다.

🔒 개인정보는 어떻게 처리하나요?

  • 원본 에듀파인 엑셀은 서버에 업로드하지 않고 현재 브라우저에서 읽고 처리합니다.
  • 출장자명·출장목적·여비금액은 지도 서비스로 전송하지 않습니다.
  • 장소 검색에는 사용자가 입력하거나 출장지에서 정리한 지도 검색용 장소명이, 거리 계산에는 필요한 출발·도착 좌표가 전달됩니다.
  • 근무지·출장지 위치와 거리 결과는 이 브라우저에 저장될 수 있으며, TMAP 데이터가 24시간 이상 재사용되지 않도록 23시간 이내에서 자동 만료합니다.
  • TMAP 사용량 보호를 위해 서버에는 날짜별 경로조회 횟수만 저장하며, 출장자명·파일명·출장지 등은 함께 저장하지 않습니다.

공용 PC이거나 저장정보를 남기고 싶지 않다면 사용 후 저장정보 모두 삭제를 이용하세요.

💡 잘 안 될 때

출장지가 엉뚱한 곳으로 검색돼요.

정확한 장소명이나 도로명주소로 다시 검색한 뒤 실제 위치를 선택하세요.

같은 출장지가 여러 번 있어요.

같은 출장지는 한 번만 위치를 확인합니다. 위치를 수정하면 연결된 출장 건의 거리도 함께 갱신됩니다.

엑셀 파일을 읽지 못해요.

에듀파인에서 내려받은 원본 `.xls` 또는 `.xlsx` 파일인지 확인하세요. 가능하면 변환하거나 내용을 수정하지 않은 파일로 다시 시도하세요.

2km 이내면 무조건 여비를 지급하지 않나요?

아닙니다. 콕검은 거리 확인을 돕는 도구입니다. 실제 이동수단, 교통비 발생 여부 및 관련 지침을 함께 확인해 최종 판단해 주세요.
