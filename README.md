# 관내여비 콕검

> **관내출장, 거리부터 콕 검토해요.**

에듀파인에서 내려받은 관내여비 자료를 불러오면 근무지와 출장지의 **보행 왕복거리**를 계산하고, **왕복 2km 이내 여부**를 확인할 수 있습니다.

출장지를 지도에서 하나씩 검색하고 거리를 계산하는 일을 줄이기 위해 만들었습니다.

**현재 버전: v0.2.19**

---

## 🧭 무엇을 하는 도구인가요

관내여비 콕검은 에듀파인 관내출장 엑셀을 기준으로 다음 작업을 돕습니다.

- `.xls`, `.xlsx` 관내여비 자료 읽기
- 동일한 출장지 자동 묶기
- 출장지의 지도 검색용 장소명 정리
- 근무지와 출장지 위치 확인
- TMAP 보행자 경로 기준 갈 때·올 때 거리 계산
- 왕복 2,000m 기준 확인
- 위치가 불명확한 장소만 `장소 선택`으로 연결
- 출장별 결과 검색·필터
- 결과 엑셀 내려받기

장소를 자동으로 확정하기 어려운 경우에는 실패로 끝내지 않고, **실제 출장지만 선택하면 거리 계산이 이어지도록** 구성했습니다.

> 이 도구는 여비 지급액을 자동으로 확정하지 않습니다. 거리 결과는 검토를 돕기 위한 확인자료이며, 최종 지급 여부는 관련 지침과 소속 기관의 적용 기준을 확인해 판단해야 합니다.

---

## 📁 에듀파인 파일은 어디서 받나요

별도 양식을 만들 필요 없이 **에듀파인에서 내려받은 원본 엑셀을 그대로** 사용합니다.

### 학교회계

**학교회계 → 지출관리 → 지출지원 → 출장여비 → 출장여비(관내) → 조회 기간 설정 → [출력] → [엑셀 저장]**

### 교특회계

**재정사업관리 → 사업재정관리 → 재무관리 → 관내여비관리 → 엑셀 저장**

파일의 열을 삭제하거나 내용을 따로 정리할 필요가 없습니다.

## 🔎 이렇게 사용해요

### 1. 파일 가져오기

에듀파인에서 내려받은 `.xls` 또는 `.xlsx` 파일을 올립니다.

인쇄용 페이지 번호, 기관명, 합계 행 등 실제 출장자료가 아닌 행은 파싱 과정에서 제외합니다.

### 2. 근무지 설정

실제 출장 출발 위치에 가까운 학교 정문 또는 주 출입구를 지정합니다.

한 번 확인한 근무지는 현재 브라우저에 잠시 저장해 다시 사용할 수 있습니다.

### 3. 거리점검

출장지 위치를 확인한 뒤 보행 왕복거리를 계산합니다.

- 정확한 장소가 확인되면 자동으로 거리 계산
- `본관`, `본원`처럼 대표 장소가 명확하면 우선 선택
- `주차장`, `분원`, `별관`, `지점` 등으로 위치가 갈리면 자동 확정하지 않음
- 장소 후보가 여러 개면 `장소 선택`으로 연결
- 장소를 선택하면 해당 출장지 거리를 바로 다시 계산

### 4. 결과 확인

출장별 왕복거리와 2km 여부를 확인합니다.

필요한 경우 검색과 필터로 확인할 항목을 좁히고 결과를 엑셀로 내려받을 수 있습니다.

## 🔒 개인정보는 이렇게 처리해요

### 브라우저에서 처리

다음 정보는 사용자의 현재 브라우저에서 읽고 처리합니다.

- 에듀파인 엑셀 원본
- 출장자명
- 출장목적
- 여비금액 등 파일에 포함된 출장 자료

**원본 엑셀 파일 전체를 서버에 업로드하지 않습니다.**

### 지도 서비스로 전달

거리와 위치를 확인하기 위해 필요한 최소 정보만 전달합니다.

- 장소 검색: 정리된 지도 검색용 장소명
- 거리 계산: 출발·도착 좌표

출장자명, 출장목적, 여비금액은 지도 검색 또는 거리 계산 요청에 포함하지 않습니다.

### 브라우저에 저장될 수 있는 정보

다음 사용에서 같은 위치를 다시 확인하는 수고를 줄이기 위해 아래 정보가 브라우저에 저장될 수 있습니다.

- 근무지 이름·주소·좌표
- 사용자가 확인한 출장지 이름·주소·좌표
- 계산한 경로 거리와 지도 표시용 경로 캐시

TMAP API로 얻은 위치·경로 데이터는 **23시간이 지나면 재사용하지 않으며 다음 접속·조회 시 저장값을 자동 정리**합니다.

화면의 `저장정보 삭제` 또는 `저장정보 모두 삭제`를 누르면 저장된 위치정보를 지울 수 있습니다.

현재 불러온 엑셀의 출장자명·출장목적 등은 `localStorage`에 저장하지 않습니다. 출장지 위치 저장 키도 원문 대신 비가역 해시값을 사용하고 출장지 원문은 저장하지 않습니다.

## 🚦 TMAP 사용량을 보호해요

TMAP 경로안내 무료 제공량을 넘지 않도록 일일 사용량을 서버에서 함께 확인합니다.

- TMAP 경로안내 무료 제공량: **1,000회/일**
- 콕검 경고: **800회부터**
- 콕검 자체 안전한도: **900회**
- 출장지 1곳의 보행 왕복거리 계산: **경로조회 2회**

900회를 넘길 수 있는 신규 거리계산은 서버에서 차단합니다.

Upstash Redis에는 개인정보를 저장하지 않고 다음 값만 저장합니다.

- 한국시간 기준 날짜
- 해당 날짜의 TMAP 보행 경로조회 누적 횟수

출장자명, 파일명, 출장지, 좌표, 출장목적, 여비금액은 사용량 카운터에 저장하지 않습니다.

## ⚠️ 결과를 볼 때 확인할 점

콕검의 거리 결과는 **지도에서 계산한 보행 경로를 기준으로 한 검토자료**입니다.

다음 경우에는 직접 한 번 더 확인하는 것을 권장합니다.

- 장소명이 불분명하거나 같은 이름의 장소가 여러 곳인 경우
- 학교 또는 출장지의 실제 출입구와 지도 위치가 다른 경우
- 왕복 2km 기준과 가까운 경우
- 실제 이동수단이나 교통비 발생 여부를 따로 확인해야 하는 경우

왕복 2km 이내라는 이유만으로 지급 여부를 자동 판단하지 않습니다.

## 🛠️ 개발 및 실행

### 로컬 실행

```bash
npm install
npm run dev
```

지도 API까지 로컬에서 확인하려면 Vercel CLI를 사용합니다.

```bash
npx vercel dev
```

프로덕션 빌드:

```bash
npm run build
```

### TMAP API

Vercel 환경변수에 TMAP App Key를 등록합니다.

```text
TMAP_APP_KEY=발급받은_앱키
```

### Upstash Redis

Vercel Marketplace에서 **Upstash for Redis**를 프로젝트에 연결합니다.

Custom Prefix를 `STORAGE`로 연결한 경우 다음 환경변수를 자동 인식합니다.

```text
STORAGE_URL
STORAGE_TOKEN
```

다음 환경변수 이름도 지원합니다.

```text
KV_REST_API_URL / KV_REST_API_TOKEN
UPSTASH_REDIS_REST_URL / UPSTASH_REDIS_REST_TOKEN
```

환경변수 값은 브라우저에 노출하지 않고 Vercel 서버 함수에서만 사용합니다.

Upstash 연결 또는 환경변수 변경 후에는 **Redeploy**가 필요합니다.

## 🚀 Vercel 배포

1. 프로젝트 파일을 GitHub 저장소에 올립니다.
2. Vercel에서 저장소를 가져옵니다.
3. `TMAP_APP_KEY`를 Production / Preview 환경에 등록합니다.
4. Upstash for Redis를 프로젝트에 연결합니다.
5. Production / Preview 환경변수가 생성됐는지 확인합니다.
6. Deploy 또는 Redeploy를 실행합니다.

## 🚫 현재 하지 않는 것

관내여비 콕검은 **출장지 거리 확인**에 집중합니다.

현재 다음 기능은 포함하지 않습니다.

- 관외출장 여비 계산
- 일비·식비·숙박비 계산
- 이동수단 입력 및 저장
- 지급액 자동 확정
- 검토 완료·보류 처리
- 에듀파인 직접 연동
- 사용자 계정·개인별 서버 저장

- OpenStreetMap 타일 통신 및 Vercel 등 호스팅 사업자의 일반 접속 로그 처리 가능성을 개인정보 안내에 명시

### v0.2.16

- 거리 계산 오류를 `위치 다시 확인`, `다시 계산`, `지도 연결 확인`, `오늘 조회 대기` 등 다음 행동으로 연결
- 오류가 발생해도 앱 전체가 실패한 것처럼 보이지 않도록 상태 문구 개선
- 결과 필터의 `실패`를 `확인 필요`로 변경
- 좌표 확인이 필요한 경우 장소 선택 화면으로 바로 연결
